# OROMAKE — Japanese Kitchen

Projeto demonstrativo independente, sem pedidos, pagamentos ou operação real.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Exportação estática

```bash
npm run lint
npm run typecheck
npm run build
```

O build estático é gerado em `out/`, pronto para uma hospedagem estática como Cloudflare Pages.

## Imagens

Fotografias reais do Pexels, com licença individual verificada e URLs de origem em [public/images/CREDITOS.md](public/images/CREDITOS.md). Arquivos WebP locais com variantes para cards e textos alternativos.

O WhatsApp pertence à VortexVision e serve para contato sobre criação de sites. Não há pedidos de alimentos.
